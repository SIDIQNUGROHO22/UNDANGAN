Pengaturan Musik Pengiring (YouTube, Offline, & Online)

Mendukung lagu dari Link Share YouTube, file lokal MP3 offline di folder project, maupun link audio online dari Google Drive/CDN.

✓ Video ID Terdeteksi

💡 Cara Ambil Link: Buka video lagu pilihan Anda di YouTube → Klik tombol "Bagikan" (Share) → Pilih "Salin Link", lalu tempelkan ke kolom di atas.

Catatan Penting YouTube: Video musik resmi dari label besar (seperti VEVO / Sony / Warner) melarang pemutaran di situs lain (Error 150/101). Jika video tidak berputar, disarankan menggunakan versi Cover Akustik, Lirik Video, atau Audio Instrumental, atau gunakan fitur Unggah File MP3 Sendiri di bawah agar 100% lancar tanpa kendala hak cipta!

💡 File MP3 yang diunggah akan otomatis tersimpan di server dan diputar saat undangan dibuka (bebas blokir YouTube & bisa offline).

Klik untuk mendengarkan lagu sebelum menyimpan (mendukung preview YouTube & file offline).

Pengaturan Gambar Tema, Kayon Gunungan, & Wayang

Kustomisasi gambar tirai Kayon Gunungan (bisa 2 gambar berbeda untuk sisi kiri & kanan), siluet wayang, dan ornamen keraton. Mendukung gambar dari Pinterest, Google Drive, link web, maupun file offline.

Tips Mengambil Gambar dari Berbagai Sumber:
  • Pinterest: Buka gambar di Pinterest → Klik Kanan pada gambar → Pilih "Salin Alamat Gambar" (Copy Image Address) yang berawalan https://i.pinimg.com/....
  • Google Drive: Anda dapat langsung memasukkan link share Google Drive (https://drive.google.com/file/d/.../view). Sistem akan otomatis mengonversinya.
  • File Offline: Taruh file gambar di folder assets/images/ dan masukkan nama filenya.
