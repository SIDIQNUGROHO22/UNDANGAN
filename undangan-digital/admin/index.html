Pengaturan Gambar Tema, Kayon Gunungan, & Wayang

Kustomisasi gambar tirai Kayon Gunungan (bisa 2 gambar berbeda untuk sisi kiri & kanan), siluet wayang, dan ornamen keraton. Mendukung gambar dari Pinterest, Google Drive, link web, maupun file offline.

Tips Mengambil Gambar dari Berbagai Sumber:
  • Pinterest: Buka gambar di Pinterest → Klik Kanan pada gambar → Pilih "Salin Alamat Gambar" (Copy Image Address) yang berawalan https://i.pinimg.com/....
  • Google Drive: Anda dapat langsung memasukkan link share Google Drive (https://drive.google.com/file/d/.../view). Sistem akan otomatis mengonversinya.
  • File Offline: Taruh file gambar di folder assets/images/ dan masukkan nama filenya.
